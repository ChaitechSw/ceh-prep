## 🚀 Getting Started

### 1. Clone and install

```bash
git clone https://github.com/ChaitechSw/ceh-prep.git
cd ceh-prep
npm install
```

### 2. Add your Groq API key

```bash
cp .env.example .env
```

Open `.env` and paste your key:
VITE_GROQ_API_KEY=gsk_your_key_here

Get a free key at [console.groq.com](https://console.groq.com)

### 3. Run locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## 🔄 Daily GitHub Update Workflow

1. Study for the day and complete all 6 tasks
2. Click **⬇ EXPORT** in the app header
3. Run the commit script:

```bash
./scripts/daily-commit.sh
```

4. Enter your notes and tools when prompted
5. Done — progress pushed to GitHub automatically
